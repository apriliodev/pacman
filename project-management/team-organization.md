## Way of working

- Source in a Git repository, work on the `main` branch.
- Features were added step by step, each one tested by playing before the
  next one (menu, then pause, then highscores, then configuration...).
- Code review: each member reads and tests the other's changes; a review
  checklist is the acceptance test plan ([acceptance-tests.md](acceptance-tests.md)).
